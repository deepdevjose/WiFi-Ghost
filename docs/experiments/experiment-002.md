# Experiment 002: Controlled Motion

## Goal

Measure whether a repeatable walking path produces a detectable channel change above the quiet-room baseline.

## Setup

Use the same transmitter, receiver, channel, and antenna orientation from Experiment 001.

## Procedure

1. Capture a quiet baseline.
2. Walk through one marked zone.
3. Return to a quiet state.
4. Repeat the same path several times.
5. Label each motion interval.

## Success Criteria

- Motion intervals are separable from quiet baseline.
- Recovery behavior is visible after motion stops.
- Raw and normalized features can be compared.
